# S1-4 票种识别与版面区域划分 — 设计（spec）

> 任务卡：S1-4 ｜ 上游：S1-3 的 `OcrLine` 列表 ｜ 下游：S1-5 字段抽取（按票种选规则）
> 状态：已实现（用户指示"继续"后直接实现；要改的点直接说，我回退）

## 1. 目标

1. **判票种**：5 类（数电票 / 旧版增值税电子普通发票 / 铁路客票 / 行程单 / 出租车票）→ 给下游选对规则；
2. **分区域**：把文本行分到 header / body / footer，并聚成 block，供字段锚定用；
3. **判不准时降级为 `unknown`**，下游走通用规则——**宁可 unknown，也不猜错**（猜错会让整页字段用错模板）。

## 2. 为什么用关键字规则，而不是分类器（D-028）

| 方案 | 结论 |
|---|---|
| 微调/训练分类器 | ❌ 训练集只有 60 张，必然过拟合；答辩也难解释"为什么用 CNN 判 5 个类" |
| 图像特征 + 聚类 | ❌ 可解释性差、维护成本高，收益不明 |
| **关键字加权 + 长宽比先验 + 互斥词扣分** | ✅ 票据标题本身就是最强的版式信号；规则可读、可调、可解释 |

## 3. 分类打分

```
score(type) = Σ(关键字权重 × 标题区加成) − Σ(互斥关键字权重) + 长宽比匹配加成
normalized  = max(0, score) / Σ(该票种所有关键字权重) × 3
```

- **标题区加成 ×3**：图像上部 15% 命中才算——票据标题几乎必在顶部，而"普通发票"这种词在备注里也可能出现；
- **标题跨行拼接**：检测常把标题切成 2–3 段（"增值税电子普" + "通发票"），逐行子串匹配会漏，所以标题区所有行拼成一条再匹配一次；
- **互斥词扣分**：数电票没有"校验码/发票代码/增值税"，旧版没有"电子发票（普通发票）"；
- **判定**：`normalized < 0.25` 或 `第一名 − 第二名 < 0.08` → `unknown`。

## 4. 区域划分（🔴 实现期修正）

- 模板用**归一化矩形**（0–1），写死像素值换分辨率就废（任务卡明确列的坑）；
- **实现期发现**：按"整图高度"归一化时，透视校正只要多框进一点桌面（实测底部多 13%），
  内容整体上移，footer 边界永远落空（footer 行数 = 0）。
  → 改为**按内容框（所有文本行的纵向范围）归一化**，对校正误差免疫；
- 落在区域缝隙的行一律归 `body`（宁可粗，不要丢行）；
- 未知票种：全部归 `body` + warning，下游走通用规则（任务卡要求）；
- block 聚类：相邻行垂直间距 ≤ 1.5 倍行高且区域相同 → 同块。

## 5. 验收（程序化）

1. **票种准确率 ≥ 0.95**（任务卡）：`scripts/layout_eval.py` 跑 60 张真实链路（预处理 → OCR → 分类），
   与标注的 `ticket_type` 比对，同时报 unknown 率与混淆矩阵——**unknown 不算判对，单列统计**；
2. **未知票种不抛异常**：空行列表 / 无关文本 → `unknown`，区域全部 body，`extractor` 仍能走通用规则；
3. **区域完备性**：每行必须且只能归一个区域；header 行 y 必须全部小于 footer 行 y（单调性）；
4. **归一化**：同一张图放大 2 倍，区域归属不变；
5. **debug 可视化**：区域带 + 行框 + 行标签画到图上，输出 `backend/eval/results/layout/`。

## 7. 连带修掉的三个预处理缺陷（都是这轮定位发现的）

判票种依赖"标题能不能读出来"，于是把 S1-2 的三个几何缺陷暴露了出来：

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 退化四边形 | 一张行程单被检成 (0,497)(1199,0)(1199,699)(0,498)——左下两点差 1px，实际是三角形，面积 50%、角度正常，全部阈值都能过；warp 后 OCR **20 行 → 0 行** | 加"最小边 ≥ max(12px, 12% 最长边)"与"对边长度差 ≤60%"校验 |
| 自交四边形 | 四角点排序后可能出现"蝴蝶结" | 加"四个连续叉积同号"校验 |
| 单边裁切 | 竖屏截图被裁成 611×1919（宽度只剩 57%、高度满格），标题整行被裁掉 | 加"一个方向 >85% 而另一个方向 <65% 判为可疑"→ 只修旋转不裁内容 |

外加：四角点越界（点跑到画面外）判为不可靠，warp 输出不得超过源图尺寸。
**结果：这三个 bug 修掉后，票种判对率从 91.7% → 100%，且 S1-2 的"几何校正成功率"从 85% 掉到 65%
——这个下降是好事**：原来的 85% 里包含了一批"warp 成功了但把内容裁坏了"的样本。

## 8. 不做

- 不做表格结构还原（行列对齐）——S1-5 用关键字锚定 + 坐标邻近即可；
- 不做多票种混合页切分；
- 不引入深度学习分类器。
