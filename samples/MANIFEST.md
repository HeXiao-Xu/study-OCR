### 1.1 R-001 的客观特征（2026-11-18 实测）

> 只做了像素统计与"关键词是否命中"的判定，**没有读取、也没有记录任何票面文字**（合规要求）。

| 属性 | 实测值 | 含义 |
|---|---|---|
| 尺寸 | 1080 × 1920（竖版，宽高比 0.562） | 手机拍摄/截图的竖向构图 |
| 容器 | JPEG（JFIF），扩展名误写为 `.png`，无 EXIF 方向标记 | 读取时不要依赖扩展名判断格式 |
| 近白像素 | **0%**（浅灰区域约 30%） | **不是扫描件**，纸面被拍成了浅灰 |
| 主色 | #923761 / #D6D0D0 / #6C434A / #AC938B / #5A1A32 | 强红紫色偏的背景 + 灰白纸面 |
| 红色像素 | **33.5%** | 背景占比大，且偏红 |
| 灰度 | 均值 129、标准差 64 | 整体偏暗、对比中等 |
| 系统 OCR 粗测 | 386 字符、43 个汉字，未命中"增值税/铁路/行程单/出租车"任一关键词 | 色偏与低对比下 OCR 不可靠，**票种无法自动判定** |

**结论**：这是"纸质票据放在红/暗色桌面上、拍得较远且偏暗"的困难工况（纸面仅占画面约 30%）。
它代表真实场景里**较难的一档**，因此：

- 合成集的成像分布要覆盖到这个区间（`scripts/verify_samples.py` 的 ④ 会检查）；
- 但它不作为准确率统计的分母（单张样本没有统计意义）。

**待办**：票种与主要字段由本人在人工核对后补录（补录时只写票种与字段**名称**，不写具体值）。

| 版面关键位置 | 标题 y≈6%；发票号码 x≈74% y≈8%；开票日期 y≈12%；购销方信息 y≈23–33%；表头 y≈38%；合计 y≈66%；价税合计 y≈70%；开票人 y≈93% | 已用于 `vat_digital` 模板的几何校准 |

**结论**：这是一份**干净的数电票电子件**，代表 2026 年的主流票种（2024-12 起全国推广）。
它带来两个直接后果：

1. 合成集必须新增 `vat_digital` 版式（已补），否则模板停在"旧版增值税电子普通发票"这个少数派上；
2. 电子发票 PDF **自带文本层**，说明"电子件走文本层、纸质件走 OCR"是一条真实存在的工程路线（见 `DECISIONS.md` D-024）。

### 2.3 成像统计对照（`scripts/make_samples.py` 会自动打印）

| 指标 | 合成集（P10 / P50 / P90） | 真实样本 R-001 |
|---|---|---|
| 灰度均值 | 108 / 152 / 192 | 129（落在合成集 P5–P95 内） |
| 灰度 σ | 36 / 56 / 73 | 64（落在合成集 P5–P95 内） |
| 纸面占比 | 23% / 69% / 100% | ~30%（属于合成集的"远景"档） |
| 红偏占比 | 0% / 1.1% / 19% | 33.5%（合成集最高 33.1%，属最难档） |

> 结论如实写进论文：**合成集覆盖了真实样本所在的工况区间（其均值/σ 落在 P5–P95），但真实样本是其中最难的一档**；
> 用合成集测出的准确率**不能**直接宣称在真实票据上同样成立。

## 3. 重新生成与复现

```bash
# 重新生成（会覆盖 samples/synth_v1 与标注文件）
rm -rf samples/synth_v1
.venv/Scripts/python.exe scripts/make_samples.py --seed 20261118

# 校验标注
.venv/Scripts/python.exe scripts/check_annotations.py --strict

# 五项自动验收（渲染一致性 / OCR 可读性 / 标注自洽 / 成像覆盖 / 划分完整）
.venv/Scripts/python.exe scripts/verify_samples.py
```

> 逐字节一致的前提：Pillow 与字体版本相同（Pillow==12.3.0、字体 msyh.ttc + arial.ttf）。
> 换机器后图像可能有像素级差异，但**标注与统计结论不变**。

## 4. 合规红线（每次加样本都要过一遍）

1. 真实票据的**图片与 PDF 一律不进 Git**；只有本文件允许写记录。
2. 真实票据的**票面文字不进日志、不进对话、不进提交信息**。
3. 对外演示/论文配图必须**脱敏**：姓名、身份证号、银行账号、住址逐项打码或等长替换。
4. 合成样本里的姓名、身份证号、税号都是**生成的假值**（身份证号校验位合法但不对应真人），不要当成真实企业信息使用。
5. 二维码只画占位方块，**不生成可扫描的二维码**（避免造出可查询的假发票号）。
