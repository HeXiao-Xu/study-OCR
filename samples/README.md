# samples/ — 票据样本目录（图片与 PDF 一律不入库）

本目录**只允许**以下内容进入 Git：

- `.gitkeep`、`README.md`（本文件）、`MANIFEST.md`（样本清单，S1-1 起维护）

以下内容被 `.gitignore` 强制排除，**永远不要提交**：

- `*.jpg` / `*.png` / `*.pdf` 等任何影像与原凭证
- 任何含姓名、身份证号、银行账号、税号原值的标注文件

## 为什么这么严

票据同时包含姓名、身份证号（火车票）、银行账号、消费时间与地点，属于《个人信息保护法》下的敏感个人信息；
多张组合还能还原个人出行与消费轨迹。**一旦进了 Git，就会留在提交历史里，删不干净。**

## 三条工作约定

1. **合成票据优先**：`scripts/make_samples.py` 可以无限生成、标注天然精确，做实验够用（见 EVAL.md）。
2. **真实票据必须脱敏**：逐项打码或等长替换，脱敏后另存，并记录到 `MANIFEST.md`（来源、授权情况、脱敏方式）。
3. **拷贝而不移动**：需要给 AI 助手看样例时，只给合成图或脱敏图，不要把原始文件复制到仓库或对话里。
